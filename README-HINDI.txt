PRINTCRAFT — PRINTING & PACKAGING WEBSITE STARTER

FILES
- index.html: website content
- style.css: responsive design
- script.js: mobile menu and WhatsApp enquiry form

HOW TO PREVIEW
1. Extract the ZIP.
2. Open the folder.
3. Double-click index.html. It should open in your browser.
4. Internet is needed for the optional Google Fonts; the site itself is plain HTML/CSS/JS.

IMPORTANT BEFORE PUBLISHING
1. Open script.js in Notepad or VS Code.
2. Find: const WHATSAPP_NUMBER = "916265947857";
3. Replace the sample number with your WhatsApp number, including India country code 91 and digits only.
4. In index.html, replace PrintCraft with your real business name.
5. Replace hello@example.com and "Your city, India" with your real contact details.
6. Check all text and contact links before publishing.

FREE HOSTING OPTION: GITHUB PAGES
1. Create/sign in to a GitHub account at https://github.com/
2. Create a new public repository, for example printcraft-website.
3. Upload index.html, style.css, and script.js to the repository root (not inside another folder).
4. Open repository Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select branch main and folder /(root), then Save.
7. Wait a few minutes. GitHub will show the published URL in Settings > Pages.
Note: GitHub Pages hosts static sites. This demo form opens WhatsApp with the enquiry filled in; it does not store submissions in a database. The visitor must press Send in WhatsApp.

ALTERNATIVE: NETLIFY
Go to https://app.netlify.com/drop and drag the extracted folder onto the page, if the current Netlify interface offers manual deploy. Follow its prompts to get a public URL.

No domain or paid hosting is required for the first demo. The site uses sample contact details until you replace them.
